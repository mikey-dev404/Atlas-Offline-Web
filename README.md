# Atlas Offline Web

The browser version of [Atlas Offline](https://github.com/mikey-dev404/atlas-offline). Workouts are stored in the browser with IndexedDB.

## Stack

React, Vite, IndexedDB

## What you can do

- Home, workout, and cardio screens
- Templates, calendar, and stats
- Use it offline after the page has loaded

## Run it

```bash
npm install
npm run dev
```
